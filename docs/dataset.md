# Dataset Documentation

> **Status:** the repository ships a **synthetic** development dataset. It validates the pipeline; it is **not** evidence of real-world performance. Replace it with real data (below) before reporting final results.

| Item | Synthetic sample (shipped) | Real dataset (to be collected by the team) |
|---|---|---|
| 1. Source | generated by `scripts/generate_sample_data.py` (fictional faculty, hand-written paper blurbs in 8 areas) | public bibliographic metadata via `scripts/collect_openalex.py`, NMIMS faculty web pages, Google Scholar (manual), faculty-supplied interests |
| 2. Size | 32 faculty, 96 papers (3 each), 8 areas, 5 departments | target >= 40 faculty and >= 5 papers each |
| 3. Format | CSV, one row per paper, faculty metadata repeated | same schema |
| 4. Labels | pairwise relevance 0/1/2, **derived** from area tags (`data/sample_relevance_pairs.csv`) | human labels, two annotators, `data/relevance_pairs.csv` (see `annotation_guidelines.md`) |
| 5. Split | queries (researchers) split 50/50 into dev/test, stratified by department, seed 42; alpha tuned on dev only | same |
| 6. Preprocessing | schema validation, whitespace/NaN cleaning, de-duplication, lowercasing, punctuation strip, rule-based lemmatisation (spaCy if installed), stop-words + academic filler removal | same |
| 7. Quality issues | tiny and clean; abstracts are 9-51 words; labels written together with data (circular, optimistic); 8 "paraphrase" and 8 "trap" faculty injected deliberately to make it non-trivial | author-name disambiguation, missing abstracts, non-English text, uneven paper counts, stale interests |
| 8. Privacy | no real persons | only public metadata of faculty; no student data; replace names by IDs before sharing outside the team; obtain faculty consent for institutional deployment |
| 9. Licence | generated by the team, free to use | OpenAlex metadata is CC0; publisher abstracts may carry copyright - store for research use, do not redistribute |

## Schema (`data/faculty_research.csv`)
`faculty_id, faculty_name, department, research_interests, paper_title, abstract, keywords, areas`
`keywords` are `;`-separated. `areas` is optional (used only to derive dev labels). Templates: `data/faculty_research_TEMPLATE.csv`.

## Collecting the real data (recommended order)
1. List faculty in `data/faculty_input.csv` (template provided) -> `python scripts/collect_openalex.py --email you@... --search`.
2. Manually verify each author's papers (remove homonyms), fill missing interests from faculty pages.
3. `python scripts/make_annotation_sheet.py` -> two annotators label independently -> `--merge` computes Cohen's kappa and writes `relevance_pairs.csv`.
4. `python -m src.evaluation.run_eval` (the run automatically picks real data + labels).
